# Codex subscription settings presentation

The Settings Environment's existing `IZCodeTaskService.codexAccount` owns account commands. This module keeps only a disposable UI projection of its safe state and never stores tokens, edits provider configuration, or starts an independent agent. It reads the injected settings service without resolving the currently active project. An absent local cwd is obtained from the injected file service.

`CodexSubscriptionCard` renders official browser or device login, cancel, refresh and logout, safe account labels, and the read-only official catalog. A local desktop client defaults to browser OAuth and retains an explicit device-code alternative; Web defaults to device code and never opens browser OAuth with the connected computer's localhost callback. The caller must explicitly allow local browser login and the injected platform must support local desktop operations; the flag defaults to false. SettingsPage sets it only for Desktop under its existing localHostServices provider, regardless of the active project's location. No user-agent detection is used. Old pending device-login snapshots remain supported.

Login methods are explicit owner commands; reading/polling never starts an authorization. Browser login snapshots contain the official authorization URL and device snapshots contain the official device page/code. Both open only after an explicit click through the platform external-link port. Validate the HTTPS OpenAI origin and path before opening; browser OAuth additionally requires PKCE/code/state and a loopback HTTP `/auth/callback` redirect. Reconnection to a browser login on Web renders a computer-login instruction, without an active authorization link. Device authorization failures use fixed localized guidance and recommend browser login only on desktop; raw error details stay excluded. Official model IDs and supported efforts are displayed without editable connection/metadata fields or entitlement promises.

Read on mount; serialize UI mutations; poll only an existing pending login; stop polling on unmount. Request generation and owner/context checks reject obsolete responses. Desktop and updated Web use the same injected owner contract. Remote transport leases remain enforced by the existing Host route. Failures are fixed localizable copy, never raw RPC errors. Mutations and malformed legacy-client writes remain the Host owner's responsibility.
